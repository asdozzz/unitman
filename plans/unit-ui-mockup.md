# Unitman — мокап экрана «Юниты» после редизайна (статичное состояние)

ASCII-мокап целевого состояния. Полная спека изменений — [unit-ui-redesign.md](unit-ui-redesign.md).

**Легенда:** `●` зелёный — Запущен · `●` красный — Ошибка · `○` серый — Готов/Остановлен ·
`⋮` — единственное меню карточки (жизненный цикл + админ + удаление) ·
`[⧉]` — копировать, появляется по hover · `┃` — красный левый акцент 3px (вместо красной рамки) ·
`▮/░` — заливка/трек бара ресурсов.

В реальной сетке на 1440px — 3–4 колонки; здесь показано по 2 для читаемости.

```text
🔍 Поиск юнита…        [ Проект: все ▾ ]   [ Мои ]                     [ ⇅ Сортировка ▾ ]    ⟳ Обновлено 2 мин назад    [ ▦ Карточки │ ▤ Воркспейс ]    [ + Юнит ]
──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
● Все 12    ● Запущен 4    ● Готов 2    ● Занят 1    ● Остановлен 3    ● Ошибка 2       ветка: fix/webhook ×   Сбросить всё ·································· 12 юнитов
──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
```

Строка 1 — тулбар (запрос + действия), строка 2 — статусы + активные фильтры + счётчик.
Больше строк в шапке нет: «Найдено: N» и «список обрезан» живут в правом краю строки 2.

## Что изменилось (выноски к карточке «Ошибка»)

1. **Название + бейдж на одной строке**, отдельная строка статуса удалена; кебаб теперь
   один — админские действия и удаление живут в нём же (группы: Жизненный цикл / Ещё /
   Админ / Удалить).
2. **Мета-строка**: relative time «12 мин назад» (абсолют — в tooltip), проект · ветка
   mono · автор.
3. **Alert-стрип вместо дублирующего текста**: сообщение об ошибке + время + действие
   «Открыть задачи» — показывается только когда есть что сказать; в здоровой карточке
   его нет. Красная рамка вокруг карточки заменена левым акцентом `┃` 3px.
4. **Действия**: primary с подписью + ghost-кнопки «Задачи»/«Сессия»; icon-only кнопки
   и второй кебаб удалены; «ждём runner» — спиннер внутри бейджа, не кнопка.
5. **Ссылки**: вся строка — ссылка (открывает в новой вкладке), хвост URL виден
   (обрезка слева), `[⧉]` — копирование по hover в ровной правой колонке 28px.
6. **CPU/MEM**: трек из токена (тема-осознанный), заливка нейтральная, цветом горит
   только значение при 70/90%; абсолюты `· 0.3 vCPU / 512 MiB` рядом, `tabular-nums`.
7. Секции разделены заголовками 11px uppercase («ССЫЛКИ»), а не линиями; «Детали» —
   раскрытие с id и переменными.

## Состояния, которых нет в статике

- **Занят** (процесс): индетерминированный лоадер 3px по верхней кромке карточки +
  спиннер в бейдже «Занят · сборка» + прогресс «3/7» в tooltip; primary-кнопка скрыта,
  команды доступны в кебабе.
- **Hover**: строка ссылки подчёркивается и показывает `[⧉]`; карточка получает
  shadow-md; кнопки — фон `--app-surface-muted`.
