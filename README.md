Unitman - сервис для создания тестовых стендов для тестировщиков, с возможностью настраивать параметры стенда. Тестовый стенд называется "юнитом". 
Пример: разработчик делает задачу, и заливает изменения в ветку в гитлаб(или аналог), Unitman отслеживает это, и автоматом создает юнит. Когда тестировщик получит задачу, то юнит уже будет собран,
и ему можно сразу приступить к тестированию, либо кастомизировать настройки юнита, если того требует задача. Килер-фича это возможность, направлять юниты друг на друга,
так как чаще всего задачи кросс-сервисные, т.е. требуют доработок сразу в нескольких проектах, без использования юнитов, приходилось задачу разбивать на последовательные шаги, 
которые приходилось заливать с релизом, для перехода на следующий шаг. Unitman позволяет ввести разработку параллельно, и без заливки промежуточных шагов, т.е. 
появилась возможность заливать только полностью готовые решения. Косвенные преимущества: возможность увидеть как долго ветки задач висят в разработке или тестировании, автоматическое 
обновление юнитов, если разработчик обновляет код, и автоудаление в случае удаления ветки после заливки в релиз. С помощью конфига юнита, можно настроить выполнение команд на юните,
например, запуск нагрузочного или юнит тестирования, посмотреть логи контейнеров приложения и т.д.
